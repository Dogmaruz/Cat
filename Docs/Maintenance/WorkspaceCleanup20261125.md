# Уборка проекта 25 ноября 2026

Рабочая игра находится в `DancingCatsClone`. В ветке сохранены сцены, ассеты Unity с `.meta`, музыка, карты, инструменты генерации и все 70 ручных посадок шапок. В `ArtSource/RadioArchipelago` остались редактируемые сцены Blender, исходные модели Tripo, итоговые модели для импорта, референсы и скрипты. Крупные оригиналы и импорты хранятся в Git LFS.

В истории разработки сохранены текстовые отчёты, параметры, ключевые иллюстрации и итоговые ролики. Черновые экспорты, дубли комплектов, сырые кадры и старые локальные сборки вынесены в `_Archive/RadioArchipelago/2026-11-25-workspace-cleanup` рядом с репозиторием. Для повторения старой проверки или отдельного исторического этапа можно вернуть исходные файлы по списку `archive-manifest.jsonl`. Пути внутри архива совпадают с путями относительно корня репозитория.

Ветка `archive/cat-before-clone-2026-10-21` сохраняет прежнюю версию `The Cat`. Локальный архив от 28 октября хранит снимок на момент переноса.
