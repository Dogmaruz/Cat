ПРИМЕРОЧНАЯ ШАПОК — РАДИОАРХИПЕЛАГ

Открыть: Unity → Radio Archipelago → Manual hat fitting → Открыть сцену.
Сцена: Assets/RadioArchipelago/Scenes/Tools/HatFittingWorkbench.unity
Работать в Edit Mode, без кнопки Play.

На стенде десять рядов: по семь шапок для каждого героя. Всего70 независимых примерок.
1. Выберите героя в окне «Примерка шапок», затем шапку. Кнопка F возле шапки приближает героя вместе с ней.
2. W — перемещение; E — поворот; R — масштаб. Все три оси независимы. Точные числа есть в окне примерки и Inspector.
3. Крутить вид вокруг героя: Alt + левая кнопка мыши. Колесо мыши — приближение. В Scene нажмите F для фокуса.
4. «Ряд героя» и «Весь стенд» показывают несколько примерок сразу.
5. Ctrl+S сохраняет все правки в этой отдельной сцене. Ctrl+Z отменяет правку.
6. «Экспортировать ВСЕ70 поз в JSON» создаёт точный снимок в соседней папке Snapshots. Достаточно сохранить сцену и сообщить об этом — параметры можно забрать без скриншотов.

Сохранение сцены и экспорт НЕ меняют игровые prefab или исходные модели.
«Применить7 поз выбранного героя» / «Применить ВСЕ70 поз в игру» — отдельные явные действия. Перед ними автоматически сохраняются резервные копии игровых prefab и таблицы в Backups.
«Создать все70 станций» пересоздаёт стенд; прежняя сохранённая сцена и снимок копируются в резервные папки. Для обычной работы используйте «Открыть сцену».

Не переименовывайте и не удаляйте служебные __WorkbenchHero__ / __EditableHatId__ объекты. Выбирая вложенную сетку шапки, вы автоматически выбираете её редактируемый корень.
Начальные позы на стенде — заготовки для вашей ручной подгонки; художественное качество всех70 сочетаний ещё не утверждено.

ОБНОВЛЕНИЕ 6 НОЯБРЯ: твои70 посадок применены в игру. Экспорт теперь сохраняет также масштаб/положение/Quaternion вложенной модели SuppliedModel; можно сохранять обе части подгонки. Для59 таких шапок созданы отдельные prefab variants без изменения исходных сеток/текстур. Полный проверенный снимок и резервные копии: Applied20261106.
