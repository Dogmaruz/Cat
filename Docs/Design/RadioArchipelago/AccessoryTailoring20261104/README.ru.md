# Подгонка исходных лямок и шапок — 4 ноября 2026

**Актуальное решение после уточнения пользователя:** исходные лямки не разрезать, не изгибать по телу и не заменять. Вернулись оригинальные подготовленные FBX-меши и пряжки. Допустима только небольшая подгонка трансформацией: сужение по X максимум на 15%, чтобы ремни проходили за руками. Высота и глубина лямок не меняются. Корпуса по-прежнему имеют одинаковую высоту 1.18 по Нори.

Запрос: использовать собственные лямки пользовательских моделей, посадить каждый из 20 рюкзаков на каждого из 10 героев, убрать отдельные петли вокруг рук. Корпуса сохраняют одинаковый физический размер по Нори (высота 1.18). Шапки должны сидеть на голове, не на рюкзаке. Музыка, уровни, генератор и сцены вне объёма этой правки. Билды не запускаются.

## Подтверждённые причины

- Прежний `FitHarness` отключал исходные Harness.L/R и создавал однотипные новые петли. В исходном прогоне 23 из 23 снятых рюкзаков имеют искусственные лямки и скрытые исходные.
- Прежний размер шапок вычислялся от ширины тела и условного коэффициента отверстия. Посадка ограничивала только глаза, без проверки головы и задней кромки.
- У Miro и Miro_Garden после прежнего разделения часть настоящих лямок оставалась внутри Case. Это подтверждено отдельными рендерами всех 20 корпусов в Blender.

## Проверка

- `Before/`: 72 исходных снимка из Unity, одинаковые камеры; данные `report.json`.
- `Iteration01/`:отклонённая первая попытка. Счётчики UV/топологии прошли, но геометрия деформировалась плохо и берет сместился вперёд. Эти снимки не являются готовым результатом.
- `After/`: отклонённые промежуточные варианты с деформацией; больше не используются.
- `OriginalFit/`: текущие 21 снимок оригинальных лямок, проверка точного совпадения вершин, UV, топологии и материалов. Исходные Mesh остаются в рендерах, новые ремни не строятся.
- `BaselineSource/`:копии затронутых исходников до правки.

Оригинальные пользовательские ZIP в Incoming не изменяются. Miro и Miro_Garden возвращены из копий до повторных разрезов (Model.fbx и editable.blend совпадают побайтово). Сохранены только уточнённые метаданные настоящего корпуса и его контакта со спиной.

`RejectedWarp/` хранит отклонённый код вне Assets. Он не компилируется и не участвует в игре. Размер шапок определяется по макушке; Руми с беретом и диадемой проверены спереди и сбоку. У других сочетаний остаются диагностические предупреждения по задним краям шапок; они не объявлены полностью исправленными.

Итоговые проверки исходных ремней: `original-fit-02.log` — 300 сочетаний и переключений прошли, новые Mesh не назначаются; `OriginalFit/report.json` подтверждает совпадение исходной формы/UV/топологии/материалов, активные родные лямки и отсутствие искусственных. `original-runtime-ui.log` — реальный Play Mode, 18 проверок применения/восстановления комплектов, 0 ошибок, пользовательские настройки восстановлены.
