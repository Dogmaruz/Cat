# Шестигранные друзы третьего острова

По запросу пользователя заменены все 11 старых вытянутых семигранных резонаторов, похожих на карандаши. Вместо них — 22 группы со 100 кристаллами. В каждой группе 2–7 шестигранных кристаллов: широкое основание, более узкие плечи, отдельная острая вершина, разные высоты, радиусы и направления. Боковые отростки наклонены наружу на31–50°, чтобы их вершины читались отдельно от центрального ствола. Матовая тёмно-фиолетовая минеральная матрица объединяет корни; молочно-фиолетовые вершины и контрастные аметистовые боковые грани подчёркивают форму. Использован прежний общий материал Crystal и плоские нормали без новых источников света, bloom или прозрачных слоёв.

Пять групп заменяют прежние дальние резонаторы; ещё17расположены вдоль маршрута. Места выбираются по настоящим треугольникам земли, а основные друзы на высоком каменном основании опираются на фактическую верхнюю поверхность Rocks. Сохранён свободный воздушный коридор: минимальное расстояние новых вершин до оси маршрута9,549м, дополнительно проверены рёбра с шагом не более0,6м на зазор8,5м. Небольшой минеральный корень заглублён в опору.

Изменён только импортируемый Moon FBX: три существующих Crystal-батча заменены с сохранением имён и материалов, три отдельных Metal-батча старых медных обручей удалены. Все266прочих мешей, включая их координаты, индексы, UV, цвета и флаги сглаживания, сохранены точно.
