# Облака, концовка и меню трёх островов

Реализованы уточнения пользователя от1ноября2026. Все изменения работают непосредственно в Unity6000.5.5f1; Player-сборок, коммитов и push не было. Новая музыка и платные генерации не запускались.

## Видимый результат

Облака имеют пять разных конструкций: низкая вытянутая гряда, высокое кучевое облако, двойная вершина с седловиной, широкое округлое облако, асимметричное облако с длинным неровным краем. Пять размеров: множители0.72/0.88/1.04/1.22/1.44. Формы и размеры распределяются сбалансированно; соседние пары отличаются. После первого цикла размеры повторяющихся форм меняются. Это отдельные цельные объёмы с мелкими клубами и плавными нормалями, без внутренних пересечений отдельных сфер.

Используются пять общих мешей (6016–15588треугольников, актуальные значения см. `Review/coherent-cloud-shapes.json`) и один непрозрачный материал. Меши создаются при настройке пула, затем только двигаются. В8небесных облаках и7облаках Moon представлены все5форм/размеров; Coral сохраняет4облака, Emerald13. Минимальный зазор с полным резервом дрейфа: Coral2.846м, Moon4.734м; верх облаков минимум .760м ниже контакта. Облака визуальные, игровые коллайдеры и музыкальные плитки прежние. Native проверки тика показывают0управляемых аллокаций.

При сборе финишных Искр герой парит, смотрит вперёд по маршруту и обращён спиной к камере. Вращение при сборе убрано; игровые обороты на Hold и больших прыжках сохранены. После настоящего конечного триггера, следующего за последним рядом собираемых сфер, герой подскакивает и улетает вверх/вдаль за1.55с. Камера фиксируется; герой постепенно уменьшается и исчезает до существующего экрана результатов. Нативные начисления, коллайдеры, музыка и двухсекундное окно победы сохранены. После retry/смены песни/выхода восстанавливаются активность, родитель, размер и локальная поза.

В домашнем выборе, библиотеке, атласе и Results Next остались только Lumi-Lai / «Изумрудная бездна», «Тико-та» / «Коралловый оазис», «Нори-но» / «Лунный резонанс». Из83исходных записей80скрыты, ни одна не удалена. Новая `Assets/Resources/RadioArchipelago/IslandMenuCatalog.asset` содержит прямые ссылки на три определения островов и их освещение. Выбор сначала привязывает нужный остров, затем готовит его настоящую карту; музыка не запускается на прежней плоской сцене. Предпочтения пользователя не меняются ради фильтрации меню.
