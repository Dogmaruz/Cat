# Источники ассетов «Радиоархипелага»

- Выбранный макет: встроенный ImageGen, первый показанный вариант, сохранён рядом
  как `selected-menu-concept.png`.
- Фон и эмблема: отдельные ассеты, полученные встроенным ImageGen редактированием
  выбранного макета; лежат в `Assets/RadioArchipelago/Art`. Runway не использовался.
- Три 3D-курьера: самостоятельные mesh-модели и материалы, созданные
  `CourierAssetBuilder`; исходники модели воспроизводятся из Editor-кода.
  Пользователь признал их слишком упрощёнными: это временные игровые модели.
- [12 референсов новых моделей](ModelReferences/README.md): встроенный ImageGen,
  отдельные front/right/left/back на каждого героя, визуальная основа — выбранный
  макет. У Люмена уточнено отсутствие шарфа, у Тико исправлен лишний задний динамик.
  Итоговые PNG сохранены в проекте без ресайза и перерисовки сторон кодом.
- TMP Essential Resources: официальный пакет из установленного `com.unity.ugui`,
  импортирован без Examples & Extras для корректной работы нового TMP-интерфейса.
- Шрифт Manrope Regular: [googlefonts/manrope](https://github.com/googlefonts/manrope),
  `fonts/ttf/manrope-regular.ttf`, SIL Open Font License 1.1. Текст лицензии
  `Assets/RadioArchipelago/Fonts/OFL.txt` сохранён вместе со шрифтом.
- Иконки: [Lucide](https://github.com/lucide-icons/lucide), ISC License.
  Оригинальные SVG сохранены как `.svg.txt`, PNG получены рендерингом этих SVG
  через Sharp. Лицензия сохранена в `Art/Icons/LICENSE.txt`. Иконки использованы
  как белые alpha-спрайты с цветом, задаваемым UI.
- Скруглённые поверхности кнопок: технические nine-slice UI-спрайты,
  воспроизводимые в `RadioArtAssetBuilder`.

Музыкальные файлы и карты в этом изменении не заменяются и не генерируются.
