# Новые модульные тела: авторинг и проверка

Подготовлены Boro, Fira, Lumen, Miro, Nori, Piko, Rumi, Soli, Tiko и Vela из десяти пользовательских Tripo ZIP. Оригинальные архивы не изменялись.

Выход: `ArtSource/RadioArchipelago/ProcessedModular/Characters/<ID>/`. Для каждого тела сохранены `Model.fbx`, редактируемый `<ID>_Rigged.blend`, `BaseColor.png`, `Normal.png`, `MetallicSmoothness.png`, `Meta.json`. Три текстуры 2048×2048; цвет и нормали скопированы, MetallicSmoothness собрана как R=metallic и A=1−roughness из исходных карт без гамма-преобразования данных.

Каждый скелет содержит ровно семь костей: root, body, head, arm.L, arm.R, foot.L, foot.R. Плечи измерены по переходу туловища в короткую горизонтальную руку. В руке одна кость от плеча до кончика, в ноге одна от верхней части короткой ноги до стопы. Костей локтя и колена нет. Существующая сетка не разрезалась; плавные веса назначены на её исходные кольца, distal arm жестко следует одной кости. Максимум три ненулевых влияния на вершину.

Редактируемый исходник и FBX сохраняют T-позу. Игровому префабу рекомендуется опустить руки приблизительно на55° от T-позы перед захватом rest pose в CourierMotion. Фактическая ось вращения должна вычисляться в визуальной системе координат после импорта FBX; угол не следует применять вслепую вокруг локальной оси кости.

Blender-система: Z вверх, лицо −Y, полная высота2.1, нижняя точка стопZ=0. FBX экспортирован с axis_forward=−Z, axis_up=Y и add_leaf_bones=False. Meta содержит реальные плечи, бедра, габариты, девять сечений поверхности и центр глаз; её координаты остаются Blender Z-up. После импорта в Unity следует учитывать FBX-преобразование.

Морф Blink создан на исходной поверхности лица по цвету глаз в UV. Новая геометрия глаз не добавлялась; нейтральное значение0. Для Unity использовать importBlendShapeNormals=None, как в прежнем ImportedCourierAssetBuilder: пересчёт морф-нормалей на почти закрытых глазах даёт выраженные складки. Это морф для краткого моргания, не отдельная длительная поза лица.

Проверка: `export-validation.json` — независимый повторный импорт всех десяти конечных FBX. Подтверждены число костей, отсутствие промежуточных суставов, сохранение числа вершин/полигонов, наличие UV, нормированные веса, конечные координаты и нулевое исходное значение Blink. `overview-front.png` и `overview-raised.png` проверены визуально для всех десяти тел; отдельные front/right/raised/blink PNG сохранены рядом.

Исходные модели плотные:84 592–92 470 треугольников на одно тело. Геометрия и UV сохранены; производительность телефона этим авторингом не измерялась. Unity Assets, сцены и настройки из этого задания подагента не менялись.

Воспроизведение: запустить body_inspect.py, затем body_author.py, body_finalize.py и body_validate.py через Blender5.2 background. Скрипты находятся в ArtSource/RadioArchipelago/Tools/Modular20261104/.
