# Модульные рюкзаки: авторинг 4 ноября 2026

Подготовлены все 20 пользовательских ZIP из `ModularCast20261102/Incoming/Backpacks`.
Исходные архивы не изменялись. Итоговые редактируемые Blender-файлы, FBX и PBR-карты
находятся в `ArtSource/RadioArchipelago/ProcessedModular/Backpacks/<ID>/`.

Каждый FBX содержит `BackpackRoot`, неподвижный `Case`, отдельные `Harness.L/R`
и `TopPivot/TopRotor`. Корпус нормализован до ширины около 1 м, Z вверх, лицо -Y.
FBX экспортирован с forward -Z/up Y. JSON хранит Blender-координаты и отдельные
поля `topPivotUnity`, `spinAxisUnity` для импортёра.

`caseBoundsMin/Max` описывает основной корпус, исключая высокую фиксированную
стойку Beacon. `fixedBoundsMin/Max` включает всю неподвижную геометрию.
`contactPlaneY` измерен по центральной мягкой подкладке; выступающие боковые
пряжки не задают отступ рюкзака от спины. `harnessColorRGB` — sRGB-медиана
реальных UV-текселей исходных лямок.

Подвижные узлы отделены в проверенных узких основаниях. Срезы закрыты с
сохранением исходных UV вокруг края. Для цельного каркаса Fira, Beacon и Helio
точка разделения перенесена ниже всех лепестков/дуг: верх вращается целиком.
На Lumen опора перенесена на вертикальную мачту, а не на нижний угол паруса.
У Beacon вертикальная стойка фиксирована и продлена до горизонтальной ступицы;
кусок стойки из вращающейся части удалён. Целый веер Helio вращается вокруг
вертикального основания вместе с обрамлением.

Исходные лямки сохранены отдельными мешами с закрытыми срезами. Их незавершённые
генератором сегменты не выдаются за восстановленные скульптурно. При сборке героя
runtime использует новые полные объёмные ленты с посадкой по поверхности тела,
а оригинальные `Harness.L/R` скрывает (ответственность runtime/asset builder).

Результаты проверок:

- `final-payload-manifest.json`: 20 комплектов, по 5 хешей FBX/PBR/Meta, все
  входные ZIP совпадают с хешами прочитанного источника.
- `final-validation.json`: обязательные узлы, независимое вращение, корректные
  UV, конечные координаты, 72 угловых положения на полном обороте.
- Минимальный вертикальный зазор вращающейся геометрии над основным корпусом
  0.02794 м. Преднамеренное соприкосновение со ступицей в эту проверку не входит.
- 19 938–30 000 треугольников на экспорт, включая исходные лямки, которые runtime
  заменяет. Источники были примерно 23–100 тысяч треугольников.
- Сохранены исходные и итоговые 3/4-ракурсы, а также отдельный итоговый кадр с
  поворотом на 75°. Финальные контактные листы: `final-back-sheet-0/1.jpg` и
  `final-turned-sheet-0/1.jpg`.

Численная проверка корпуса не заменяет проверку пересечений с головой, шапкой
или новым объёмным ремнём на конкретном персонаже. Эти сочетания проверяются в
Unity после создания профилей посадки.

Эти игровые render-меши не объявляются герметичными моделями для печати:
исходные тонкие слои и редукция оставляют отдельные открытые рёбра; их количество
по каждому мешу явно сохранено в `final-validation.json`. PASS относится к
перечисленным UV/узлам/координатам/вращению и зазору, а не к manifold-топологии.

Воспроизводимый порядок инструментов:

1. Blender: `pack_author.py` (все ID либо нужные ID после `--`).
2. Blender: `pack_validate.py` (проверяет сохранённые editable.blend).
3. Обычный Python с Pillow/numpy: `pack_finalize.py` (цвета лямок, хеши, листы).

Все скрипты расположены в `ArtSource/RadioArchipelago/Tools/Modular20261104/`.
Unity-проект этим агентом не открывался и не изменялся; билдов не было.
