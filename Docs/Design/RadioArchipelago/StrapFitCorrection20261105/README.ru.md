# Посадка лямок: уточнения 5 ноября 2026

Последние требования пользователя:

- Рюкзак сохраняет прежнюю высоту. Можно немного приблизить его к спине, допускается небольшое пересечение с телом.
- Опускается верхняя дуга лямки, чтобы обходить ухо.
- Петля доходит перед всей рукой, а не до центра плеча.
- Нижняя ветвь находится немного ниже руки. Размеры рюкзака и принятый верхний контур при этой корректировке сохраняются.
- Исходные лямки, UV, фактура и фурнитура сохраняются. Билды не собираются.

Реализация: корень и четыре направляющие на рюкзак (Front.Left/Right и Upper.Left/Right). Плавные веса дают до трёх влияний на вершину, используется Bone4. Верхние направляющие опускают только верхнюю часть; передние направляющие выводят нижнюю ветвь наружу и немного вниз. Корпус не опускается. Позиция корпуса по Z сдвинута на 0.04 единицы авторинга к спине; размер корпуса 1.18 по Нори.

Границы берутся по реальной позированной геометрии рук. Вынос рассчитывается по более короткой лямке из двух; запас перед рукой — 0.065. Металлические компоненты получают одинаковые полные наборы весов F/A, чтобы двигаться жёстко без растяжения; дубликаты вершин UV-швов согласованы.

`Baseline/` и `Before/` сохраняют исходное состояние. `After/` — текущие нативные ракурсы. Снимок без тела используется только для диагностики непрерывности лямки. Промежуточный вариант с опущенным целиком рюкзаком отклонён пользователем и отменён.

Диагностика выявила два разных эффекта у нижней фурнитуры: перекрытие телом/рукой и растяжение металлических групп переходными весами. Отдельное максимальное расстояние между исходными совпадениями Case/Harness у Orbit относится к субмиллиметровому исходному обрывку из трёх вершин; оно не равно разрыву настоящего заднего крепления. В отчёте эти показатели разделены.

Последняя корректировка нижней ветви: `harnessLowerDrop` опускает только переднюю/нижнюю направляющую; Upper сохраняет прежнюю позицию. Величина зависит от реальной высоты руки и учитывает частичные веса вершин. Высота корпуса — исходная, `packLowering=0` во всех 200 записях.

Актуальные проверки: `lower-wrist-clearance.log` завершён с кодом 0, 300 переключений/комплектов и независимая проверка 200 надетых рюкзаков прошли. `skin-checks.json` проверяет пять костей, CPU/BakeMesh, неподвижные крепления/корпуса и одинаковые полные наборы весов/смещений всех металлических компонентов. `skinning.json` подтверждает исходную геометрию, UV, нормали, топологию и жёсткие веса фурнитуры. `After/` содержит 60 статических видов фирменных комплектов, кадр без тела и четыре кадра Руми в idle/полёте. `rumi-lower-final.png` — точная копия свежего нативного бокового кадра.

Численные проверки всех 200 сочетаний не означают художественного просмотра всех смешанных комплектов: визуально просмотрены фирменные комплекты и отдельно Руми. Билды не собирались, музыка, уровни и прежняя анимация персонажей не менялись.

`play-mode-final.log` / `PlayMode/report.json`: реальный Play Mode и Мастерская, 18 проверок, 0 ошибок, восстановление пользовательских настроек после проверки. Изображение `rumi-lower-final.png` побайтово совпадает со свежим кадром `After/Rumi__backpack_Rumi_Orbit__side.png`.
