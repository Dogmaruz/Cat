# Коралловый оазис: второй остров в Unity

Создан по одобренному концепту, 30 октября 2026. Отдельная сцена — `DancingCatsClone/Assets/RadioArchipelago/Scenes/CoralOasisPilot.unity`. Запуск: Play в Unity, затем «Играть». Для проверки пока используется Lumi-Lai; новая музыка не генерировалась. Первый остров и Editor Build Settings не заменены.

Окружение: плавающие слоистые терракотовые скалы с цельным низом, семь высоких каменных гребней, пальмы и цветочные группы, два радиодомика, башня с кольцевой антенной, физическая чаша оазиса, каменистые берега, источник и два водопада с шейдерным потоком. Сплошного дорожного покрытия нет. Плитки парят над землёй и разрывами.

Маршрут: 713.9945 м, широкие S-повороты обоих направлений, минимальный радиус 21.54 м, подъёмы/спуски от 4 до 16.97585 м. Ровные вводные и финишные участки. Производная карта — 195 опор, 18 удержаний, 50 подвижных плиток; обычный радиус .65 м. Длинные опоры остаются прямыми по вертикали, музыкальные времена сохранены.

## Исправление экспорта

Финальная визуальная проверка также обнаружила декоративные остатки мостовой над пустотой. Вместо номинальной высоты экспортёр теперь проверяет опоры настоящим Terrain BVH: 374 группы проверены, 24 неподдерживаемые группы убраны, 259 выровнены; стебли цветов привязаны к реальным треугольникам. Незакреплённые компоненты во вступлении: 495 → 0. Добавлены мокрые берега и неровные камни у источника. Нормаль водного шейдера больше не переворачивается второй раз после зеркального FBX-перехода: вода освещается сверху. Свежие кадры 7.4 и 19.4 секунд в финальном прогоне подтверждают исправления. Ранний игровой PASS до этой косметической правки сохранён в `Review/BeforeFinalCosmetics/`.

Первый просмотр в Unity обнаружил перевёрнутые поверхности: переориентация нормалей после разбиения на открытые пространственные фрагменты разворачивала 16,192 треугольника Terrain. Диагностический двусторонний рендер подтвердил причину; эта временная команда удалена. Экспортёр теперь ориентирует полные исходные тела до разбиения и сохраняет порядок граней после него. Свежий FBX: 72,192 Terrain вверх / 0 вниз; 1,744 Water вверх / 0 вниз. Unity отрисовывает полные поверхности с обычным отсечением обратных граней. `Review/WindingBaseline` сохранён как диагностическая история.

Актуальный FBX: 259 мешей, 1,300,354 треугольников; SHA-256 `4CC6A188004F508AE440E79A69BF80E3E1488ED45768F82B30871BE2B2A713FC`.

Билды и платные генерации не выполнялись. Проверка производительности на телефоне в эту задачу не входила. Переходы между островами и отдельная новая песня не добавлялись: готова отдельная игровая сцена для теста.
