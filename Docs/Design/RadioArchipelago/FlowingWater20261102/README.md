Пользователь указал, что прежние переливы воспринимаются как статичная вода. В старом варианте два слоя нормалей медленно двигались в противоположных направлениях: это давало мерцание, но почти не давало читаемого переноса рисунка при быстром движении камеры.

Обновлён только общий `CoralWater.shader` и Editor-only `LivingWaterReview`. Семь существующих водных материалов, shared256pxтекстура, три FBX, музыка, карты, маршруты и сцены не менялись.

Оба слоя волн теперь переносятся одним течением. Редкие мягкие пятна/обрывки пены сохраняют форму во время перемещения, поэтому направление можно заметить за короткий взгляд. Второй слой имеет небольшое боковое отклонение; широкое отражение неба немного приглушено, чтобы движение не терялось в белом блеске. У водопадов вдоль листа движутся выраженные нити потока и короткие пенистые участки. Прежние геометрические белые и тёмные полосы остаются скрытыми. Колебания реальной поверхности по-прежнему ограничены7см/6,5см; новых объектов, симуляции жидкости, источников света, SSR или bloom нет.

## Контракт материалов Amber

- `_CurrentSpeed`: метры переноса на одну секунду шейдерного flow-time; default3,2. Скорость в игровых секундах равна `_CurrentSpeed × _FlowSpeed`. Для прежних бассейнов с `_FlowSpeed=.55` это1,76м/с вместо приблизительно0,2м/с прежнего встречного дрейфа.
- `_FlowDirection`: world-XZ направление обычной поверхности; default(.8,0,.6,0).
- `_UseFlowUV`: default0 для обычных бассейнов. AmberStream использует1: UV0.U идёт0..1 поперёк, UV0.V — расстояние вдоль русла в метрах, возрастающее вниз по течению. Нормали для такого русла разворачиваются по производным UV/геометрии.
- Рекомендация AmberStream: `_CurrentSpeed=4..4.5`, `_FlowSpeed=.65` (2,6–2,9м/с); для более спокойных бассейнов `_CurrentSpeed=1.8..2.5`.
- Waterfall сохраняет `_Fall=1`, `_FlowSpeed=1.3`, прежние alpha-blend/queue/ZWrite, shared normal-data texture. Вертикальные детали движутся вниз примерно на`10 × _FlowSpeed`м/с. `_WaterPreviewTime=-1` остаётся обязательным runtime default.

Новый поток по UV компилируется в общем шейдере; его конкретное положение на четвёртом острове проверяется после импорта Amber. Повороты воды, камни и камыши вокруг нового русла принадлежат отдельному авторингу острова.
