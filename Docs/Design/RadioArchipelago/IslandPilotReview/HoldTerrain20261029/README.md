# Полная длинная плитка и проверка пересечений с островом

Запрос от 29 октября 2026: длинная керамическая плитка должна сохранять длину; только полупрозрачная полоса отображает прогресс как в исходной механике. Радиометка должна быть точно на конце линии. Часть плиток оказалась за поверхностью острова, что не проверял прошлый прогон по нативным коллайдерам.

## Исходное воспроизведение

Запись пользователя: `C:/Users/Derek/Videos/Запись 2026-10-28 233701.mp4`, 75,71 с, 490×872, 30 кадров/с. Пользователь уточнил основное падение: **25-я секунда видео, 14% уровня**, затем возврат в игру. Кадры `failure-24-0.png`, `failure-25-0.png`, `failure-26-0.png` сохранены в `Video/`. Соответствующие цели — source64/65, музыкальное время около 22,85–23,06 с, маршрут около s175–177 м. Первоначальная трактовка белого объекта у скалы на 67-й секунде как линии проката не подтвердилась: по форме это стрекоза; отображаемого Follow-path меша в данной реализации нет. Изменять корректное преобразование локальных эффектов из-за этого объекта нельзя.

Подтверждённые причины механики удержания: `IslandHoldSurface.Advance` уменьшал меш тела, а `IslandParticleProjection` переносил родной заполняемый след на оставшийся интервал. Собственная радиометка имела дополнительное боковое смещение и опережение относительно начала белой линии. Эти намеренные прежние решения больше не соответствуют новому запросу.

**Подтверждённая причина основного падения:** процедурная финишная поляна создавалась активной уже при BindTrack. Маршрут повторяет географию, поэтому её поверхность перекрывала ранний проход. Независимая проверка с теми же сгенерированными мешами нашла у source64: верх плитки 1,011767 м, низ 0,711767 м, поверхность поляны 1,006160 м. Погружено 0,294393 м тела, видимыми остаются лишь 5,6 мм глазури — это соответствует белым пятнам на видео. Эта поляна не входит в основной FBX, поэтому предыдущая проверка импортированного острова её не учитывала. Проверка логических коллайдеров тоже не могла обнаружить визуальную преграду.

Исправление времени жизни: поляна конструируется неактивной и включается только при полном, не завёрнутом по длине острова chartZ около 989,43 м. Последняя ранняя цель в её площади находится на chartZ592,35 м; до неё ещё нет видимого финишного грунта. При финальном прыжке, приземлении и сборе искр поляна активна. Повторение маршрута и сброс уровня проверяются отдельно.

Дополнительная проверка настоящих треугольников по полной ширине ±3,82 м нашла отдельные касания моста/камней. Первое исследование только положительного winding неполно: импортированные зеркальные меши требуют обеих ориентаций. Оно сохранено как superseded. Исправление высоты применяется локально **после компиляции принятой карты**, не меняя её JSON. Итоговые проверки: 0 пересечений коридора и опор, минимальный зазор под телом 0,505 м / 0,453 м. Максимальный локальный подъём 0,934 м, максимальный уклон 0,656; прямой вертикальный профиль полных удержаний и их торцов сохраняется. Проверки линий видимости в обоих пользовательских окнах по основному FBX не выявили преград; основной дефект воспроизведён именно на генерируемой поляне.

## Ограничения и проверка

Музыка, исходные карты, основной FBX острова, коллайдеры и тайминги сохраняются. Исправляется производный тестовый уровень. Высота длинных опор остаётся одной прямой по вертикали; горизонтальный изгиб допускается. Подложка сохраняет родную анимацию, а маркер совпадает с вершиной линии без бокового ответвления. Полное тело исчезает при нормальном завершении/отпружинивании, не во время проката.

Проверяются неизменность всех вершин тела при прогрессе, прикрепление маркера, реальные статические/скелетные родные полосы, треугольники поверхности по полной ширине и всем плиткам, а затем настоящий полный прогон и кадры проблемного участка. Старые исходные значения производного уровня сохранены в `Baseline/`. Player/APK не собираются.
