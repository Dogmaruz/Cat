# Раскачивание камеры на прокатах — 28 октября 2026

Запись пользователя: `C:/Users/Derek/Videos/Запись 2026-10-28.mp4` (38,49 с, 514 × 880).
Видеоанализ и измерения статичного фона: [REVIEW.md](REVIEW.md).

На длинной плитке около 29,83–30,70 с неподвижные деревья семь раз меняют направление горизонтального движения на экране. Около 31,33 с есть отдельное резкое перекадрирование. Неровная частота записанных кадров тоже присутствует, но сама по себе не объясняет смену направления движения фона.

## Подтверждённая причина

Предыдущая защита от выхода за экран учитывала меняющийся мировой `Renderer.bounds` героя **после** сглаживания камеры. Этот объём включает запас для анимации. При вращении и сплющивании героя на прямой дороге его размеры меняются; камера немедленно отступает под новый объём, затем плавно возвращается. Исправление границ кадра создало раскачивание.

Дополнительные источники скачков: боковой ввод влиял на положение камеры, прыжок менял её защитный объём, а выбор следующей плитки после начала проката мог сразу перескочить за весь длинный участок. Последняя коррекция применялась без сглаживания.

Контрольный тест вызывает реальный `IslandStagePresentation.ApplyCamera` на неподвижной дороге и вращает/сплющивает только модель с анимационным запасом габаритов. До исправления за 360 поз камера смещалась до **4,17377 м** (`Before/stability-red.json`). Это изолированный тест, не оценка расстояния по видео.

## Исправление

- Положение и направление камеры определяет только продвижение по маршруту.
- Постоянный запас пространства учитывает обе полосы, максимальный полёт и участок дороги впереди. Он не меняется от анимации, удержания, бокового управления или смены номера следующей плитки.
- Кадрирование вычисляется для желаемого положения **до** сглаживания. В конце кадра дополнительного мгновенного сдвига больше нет.
- Меняющиеся границы модели остаются только в системе скрытия препятствий перед героем.
- Тот же тест 360 поз после исправления: **0 м смещения**, 0° поворота камеры, 0 изменения FOV (`After/camera-stability-checks.json`).
- Полный прогон дополнительно выявил движение родителя камеры в финишной анимации исходной трассы. Проверка не исключает финиш: камера теперь хранит собственные сглаженные мировые координаты и не считывает унаследованный сдвиг родителя обратно в расчёт. Отдельный тест сдвигает родителя 60 раз на неподвижной дороге (`Before/carrier-red.json` — ошибка до исправления).

Полный игровой прогон дополнен проверкой фактической позиции и вращения камеры относительно её сглаженной цели на каждом последовательном кадре. Проверки границ героя/ближайшей плитки сохранены. Для воспроизведения записи используется Люмен (индекс 1); его выбор и остальные пользовательские настройки затем восстанавливаются.

Музыка, карты, генератор, анимация персонажа и правила управления не изменяются. APK не собирается.
