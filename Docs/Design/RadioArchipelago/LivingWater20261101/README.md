# Живая вода — 1 ноября 2026

Обновлена визуальная вода на трёх готовых островах. Первый остров прежде использовал статичный `Island Surface` для воды; теперь все бассейны, ручьи и каскады используют общий `Coral Water`. Игровые коллайдеры, карты, музыка, маршрут, камера и FBX-геометрия этой правкой не менялись.

Одна общая бесшовная карта нормалей 256×256 даёт пересекающиеся волны и мелкую рябь. Два слоя движутся с разными скоростями/масштабом. Блики и светлое отражение неба зависят от направления взгляда и подвижной нормали; цвет воды сохраняет исходные оттенки острова. Небольшое движение поверхности ограничено 7 см, колебание каскадной поверхности — 6,5 см. Полосы не рисуются синусоидой поверх цвета.

Прежние отдельные геометрические нити пены скрыты через `_FoamLayer`; у Emerald белые и тёмные статичные нити отделяются по исходному цвету вершин (`_VertexFoam`). Мягкая пена и световые гребни теперь принадлежат самой движущейся поверхности. Каскады имеют направленный вниз поток двух масштабов, колеблющуюся поверхность и мягкое исчезновение в глубокой воздушной части. Только два материала `Waterfall` используют прозрачное смешивание и очередь3000/ZWrite0; обычная вода остаётся непрозрачной. Дизеринг в финальной версии не используется.

Карта `WaterRippleNormal.png` — вычисленные данные нормали XYZ в RGB и высоты в A, а не изображение воды. Она импортируется как **linear Default Texture**, Repeat, с mipmaps; ручное декодирование RGB не предполагает AG-переупаковки Unity Normal Map. Воспроизводимый генератор: `ArtSource/RadioArchipelago/Water/20261101/generate_ripples.py`.

Нет новых runtime-объектов, симуляции жидкости, источников света, SSR или bloom. Работа выполняется в существующем шейдерном проходе; одна текстура разделяется между материалами. Производительность на телефоне не измерялась, Player build не создавался.

## Проверка

`LivingWaterReview` — Editor-only инструмент просмотра настоящих импортированных prefab, не игровая сцена. `living-water-review` снимает по10кадров бассейна/каскада каждого острова с неизменной камерой, используя только временные копии материалов для заданного времени. Все шесть видов прошли проверку видимого движения. В финальной версии доля изменившихся пикселей воды: Emerald55,2%/62,1%, Coral74,4%/8,4%, Moon82,9%/77,3%. Для демонстрации полезнее `Review/coral-pool.gif`, `Review/moon-pool.gif`, `Review/emerald-pool.gif` и `Review/moon-cascade.gif`. Все GIF собраны из настоящих Unity-кадров.

`living-water-live` отдельно проверяет **настоящий `_Time` в Play Mode**, без clock override: время0,251253→1,552274с, изменились65786из77847пикселей воды. Используется временная пустая сцена только с пейзажем, камерой и освещением, без игровых/профильных/звуковых контроллеров; исходный `MoonResonancePilot` затем восстановлен в чистом Edit Mode. Отчёт `Review/live-clock.json`.

Native `island-abyss-checks` и `moon-checks` после финальной воды — PASS. `coral-checks` дошёл до исторической проверки сохранности первого острова и отклонил уже разрешённые изменения домика/воды: root обновляет этот контроль точными проверенными SHA перед общим прогоном после правки механизмов на крышах. Это оставшаяся проверка версии ассетов, не ошибка компиляции/отрисовки воды.

Изолированные пейзажные кадры не являются полным прохождением уровня. `*-cascade-full.png` — дополнительные дальние контекстные ракурсы; некоторые направлены ниже исчезающего каскада и содержат в основном скалы. Для проверки самого потока используются верхние крупные виды и GIF, а не эти дальние кадры.

## Изменённые материалы и код

Семь материалов перечислены в `material-changes.json`: исходные значения float сохранены; у пяти водных материалов добавлена одна ссылка на shared normal-map, у двух материалов Foam флаг `_FoamLayer`, у Emerald — новый водный шейдер/параметры, у двух Waterfall — прозрачные render states. Точные исходные и текущие SHA, добавленные поля и первоначальные файлы сохранены рядом в `Before/`.

Изменены `CoralWater.shader`, `IslandAbyssJobs` (водная привязка/допустимый shader), `CoralOasisIslandJobs` (водный авторинг), добавлены `LivingWaterReview` и два его пункта в локальную очередь Editor. Соответствующие строки `MoonResonanceIslandJobs.MaterialFor` добавляет root. Новые ссылки сохраняются также при последующем авторинге островов.

Во время передачи root: очередь свободна, никаких дальнейших Unity-вызовов или записей в Assets со стороны water-agent нет. Все карты/аудио/модели сохранены; дальнейшая установка rooftop-моделей относится к другому заданию.
