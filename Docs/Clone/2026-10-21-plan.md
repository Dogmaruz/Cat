# Dancing Cats clone implementation plan

> **For agentic workers:** execute independent recovery/data tasks in parallel; root owns integration and validation. Keep the old project frozen.

**Goal:** reproduce the selected original game's offline content and behavior in a separate project, with preserved history.

**Architecture:** import recovered original assets and UI hierarchies into a fresh URP project, bind them to newly reconstructed gameplay using original maps and native/runtime evidence. Never compile advertising/payment SDK stubs or use the previous prototype as the product.

**Tech Stack:** Unity 6000.5.4f1, URP17.5, Input System1.19, uGUI2.5; UnityPy1.25.4, AssetRipper2.0, IL2CppDumper/Ghidra and a fresh Android emulator for evidence.

**Spec:** `Docs/Clone/2026-10-21-design.md`.

## Completed gameplay/UI evidence

- Core checks: native formulas/scoring, 63 rigs/305 spring bones, progression, seven authored Hold variants, seven themes/114 materials and recovered-data 6/6, including all 58 songs/maps/previews loading. Menus16 also confirms 618 sprites and all 166 configured heads resolve.
- Earlier chart assertions cover UnityPop054, AllAlonePop with Hold/Follow and FlyingPop through three actual endless laps to 9 marks. Recovery assertions cover Hold exit replay after revive without duplicate point scores and protected misses that still require the real final platform.
- **Menus16 PASS:** actual Input System/EventSystem pointer routing through start/pause/modal cancel, seven panels, animated dice reward/claim, daily card reveal and cat unlock, shop equip/live actor update, and login reward once.
- **Challenge18 PASS:** actual challenge selection/start, three complete laps, 9-mark result overlay and one 500 + 1000 + 1500 reward claim while retaining normal settlement.
- **Windows PASS:** build size 267,207,227 bytes, two obsolete-API warnings; standalone startup reaches READY with 58 songs, 63 cats and 618 sprites without product runtime errors. Full gameplay/input coverage above remains Editor evidence.

Detailed evidence and run limitations are in `Docs/Clone/RECOVERY.md`. Data coverage of 58 entries does not mean all 58 were manually played. Original reference 3D fails on the available emulator; full pixel/audio-perceptual parity is unverified, URP shaders are reconstructed, and challenge-song selection uses an explicit offline policy. Android/device and final publication tasks remain open.

## Review focus

- Missing remote resources must never silently select a different song or claim an unlock succeeded.
- Multiple tile boundaries crossed during a long frame must retain ordering and single scoring.
- Pause/revive/endless restarts must preserve scheduled audio/map timing and re-anchor held input.
- Restored UI package components must resolve to installed uGUI/TMP scripts; missing custom SDK stubs must not start or compile.
- Source saves and the archived project's contents must remain unchanged during clone validation.
