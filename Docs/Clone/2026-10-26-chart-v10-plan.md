# Short Hold and remaining Can Can Follow implementation plan

**Goal:** Increase correct short-Hold recognition, reduce false proposals, and recover additional Can Can glide families. Publish only separate test levels; preserve originals and earlier playable maps. No player builds.

**Architecture:** Keep source measurements, gesture classification, native compilation and lateral choreography separate. Reuse verified local mixed-note/vocal evidence. References are evaluation/training labels only, never inference inputs. Preserve legacy accepted supports and flights. Remain experimental if cross-song quality does not justify a default change.

**Baseline:** `9c40389`, v9 with experimental short supports explicitly enabled to match the existing test maps. All eight previously studied recordings are now known tuning/regression data. Strict interval matching remains unchanged: short Hold <=.45s on both sides, onset/end <=80ms, IoU>=.5; Follow onset<=80ms, end<=150ms, IoU>=.5; maximum-cardinality one-to-one assignments.

**Approach:** Diagnose source/endpoint coverage and repeated musical context before changing rules. Compare interpretable source-based phrase rules and a regularized policy under leave-one-song-out. Broadly lowering thresholds is rejected because v9 already demonstrated excess false supports. Can Can needs additional articulated phrase families, not reference timestamps or a forced count.

**Independent check:** Select Für Elise and Jingle Bells by aggregate type/duration density and distinct audio hashes. Their event times, signal features and candidate errors remain unopened by implementers until the algorithm is frozen. Source-only preprocessing and sealed baseline preparation may run before freeze without opening results. After evaluation they cannot be reused as unseen data.

## Review focus

- Short audible notes with ordinary attacks must not all become Hold; measure false supports separately from matching onset times.
- Repeated musical context must not encode song identity, absolute timestamp, source-label duration or reference path.
- New support families must not overlap accepted legacy Hold/Follow/BigJump or make short outgoing jumps unreachable.
- Silent, ambiguous, anti-phase or polyphonic evidence must remain conservative and source-verified.
- Calibration gain is not independent accuracy; runtime completion is not musical correctness.
