# Dancing Cats Offline Clone

Отдельный Unity-проект для офлайн-реконструкции Dancing Cats 0.5.8/build113. Старый проект `The Cat/` не используется игровым кодом.

Открывать через Unity Hub в **Unity6000.5.4f1**, сцена `Assets/Clone/Scenes/DancingCats.unity`.

В проекте58 песен с исходными картами,63 кота, оригинальные модели, текстуры, анимации и панели интерфейса. Карты загружаются из JSON в `Assets/Resources/OriginalData/Maps/`; это восстановленные авторские данные, а не процедурная разметка музыки. Игровая логика заново реализована по данным и нативному коду оригинальной сборки.

Игра начинается при нажатии на игровое поле. Удерживайте палец или левую кнопку мыши и ведите кота по горизонтали. Escape открывает паузу. Кнопки наград с исходной иконкой видео выполняют локальное действие; рекламные и платёжные SDK не подключены. Прогресс сохраняется отдельно в пространстве `DancingCatsClone.v1`.

## Проверка и сборка

Editor-методы находятся в пространстве имён `DancingCats.Clone.Editor`:

- `ClonePlayerBuild.Verify` — данные всех58 песен, нативные правила,63 анимированных рига, награды/сохранения, семь вариантов Hold и смена тем.
- `IntegratedPlayValidation.Run` — ввод через Input System, прохождение исходных уровней, пауза, промах, возрождение, три круга endless и открытие панелей.
- `IntegratedPlayValidation.RunInterfaceAndRecovery` — запуск по нажатию, повторный выход с Hold после возрождения, промах у финиша под неуязвимостью, панели и локальные награды кубика.
- `IntegratedPlayValidation.RunMenus` — реальные нажатия по исходным кнопкам: обучение, запуск, подтверждение выхода, семь панелей, кубик, карточная награда, выбор кота и ежедневный вход.
- `IntegratedPlayValidation.RunChallenge` — выбор испытания, запуск по нажатию, три полных круга до 9 отметок и однократная выдача 500 + 1000 + 1500 монет.
- `ClonePlayerBuild.Windows` / `ClonePlayerBuild.Android` — сборка. Перед запуском установите `DANCING_CATS_BUILD_OUTPUT` в папку назначения.

При запуске Unity из CLI укажите целевую платформу до вызова метода: `-buildTarget Win64 -executeMethod DancingCats.Clone.Editor.ClonePlayerBuild.Windows` либо `-buildTarget Android -executeMethod DancingCats.Clone.Editor.ClonePlayerBuild.Android`. Сборщик проверяет соответствие активной платформы: одного `BuildPlayerOptions.target` недостаточно для корректной подготовки URP-шейдеров.

На 21 октября 2026 года финальный `release-final-verify.log` подтверждает все основные проверки: данные/правила, 63 рига, Hold, темы и 618 спрайтов. Editor-прогоны **Menus19** и **Challenge18** завершились успешно; Menus19 также проверяет активный исходный звук кнопок и отсутствие предупреждений о выключенном AudioSource. Ранее проверены полные карты Unity/AllAlone и три круга Flying, пауза/возрождение, повторный выход с Hold без повторных очков и обязательный контакт с настоящим финишем.

Финальные Windows и Android ARM64 сборки содержат один и тот же проверенный игровой код; каждая собрана с двумя предупреждениями об устаревшем API. Отдельный запуск Windows подтвердил каталог из 58 песен, 63 котов и 618 спрайтов без ошибок игрового кода. Размер итогового APK — 124 918 630 байт. Повторный офлайн-прогон именно этого APK в эмуляторе API 36 прошёл с настройками High: корректная 3D-графика, сенсорный запуск, пауза/продолжение, промах и возрождение через Continue. Предупреждений о выключенном AudioSource, шейдерах и исключений C# не было. Проверки на физическом Android-устройстве не было. Исходный снимок `e9bc5a7` опубликован; финальные проверенные исправления и отчёт подготовлены для заключительного коммита.

Все 58 песен проверены на загрузку данных и ресурсов; полное прохождение выполнено на выбранных картах, а не вручную на всём каталоге. Полное пиксельное совпадение не подтверждено: исходные 3D-шейдеры не работают в доступном эмуляторе, а шейдеры проекта восстановлены для URP. Выбор песни ежедневного испытания адаптирован для офлайна. Полные прохождения карт выполнены в Editor; Windows-прогон подтверждает запуск и ресурсы, Android-прогон — перечисленные короткие игровые действия.

Происхождение данных, история и точные границы проверки: [RECOVERY.md](../Docs/Clone/RECOVERY.md). Старое состояние сохранено в ветке `archive/cat-before-clone-2026-10-21`.
