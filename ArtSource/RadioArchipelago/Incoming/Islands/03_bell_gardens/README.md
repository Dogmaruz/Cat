# 03_bell_gardens

Положи сюда модель острова: GLB или FBX с текстурами. Референсы находятся в ArtSource/RadioArchipelago/Islands/ReferencePack_v1/03_bell_gardens/.

По возможности оставь отдельными объектами основание, непрерывную дорогу, здания, деревья и крупный декор. Музыкальные плитки в модель не добавляй. Переднюю сторону ориентируем на юг; вид front — с юга, сверху north up. Масштаб, оси экспорта и окончательную дорогу проверим при импорте в Unity.

Это папка для передачи модели; автоматический импорт и изменение уровней сейчас не выполняются.
